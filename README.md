# QRICardReader

Verifier for cryptographically signed I-Cards generated by [QRICard](https://github.com/sarathrajendran552/QRICard).

Scans the QR code on the back of an I-Card, verifies the RSA-2048 / SHA-256 signature against the issuer's certificate, extracts all cardholder details and the embedded face photo, and reports whether the card is authentic or has been tampered with.

---

## How verification works

```
icard_back.png
      │
      ▼
  Decode QR  →  decimal string
      │
      ▼
  int → bytes  →  gzip decompress
      │
      ▼
  signed_data  |  signature (last 256 bytes)
      │                   │
      ▼                   ▼
  SHA-256 hash     RSA decrypt with
  of all fields    public key from cert
  + photo bytes         │
      │                  │
      └──── compare ─────┘
               │
        ✓ match = VALID
        ✗ mismatch = INVALID (tampered or wrong key)
```

## Setup

```bash
uv sync
# or
pip install zxing-cpp pillow opencv-python cryptography
```

> **OpenJPEG** is required for JP2 photo extraction:
> ```bash
> sudo apt install libopenjp2-7        # Debian / Kali
> sudo pacman -S openjpeg2             # Arch
> ```

---

## Usage

```bash
python3 qricardreader.py \
  --image icard_back.png \
  --cert  icard_sign.cer
```

### Options

| Flag | Default | Description |
|---|---|---|
| `--image` | `icard_back.png` | Path to the card back image |
| `--cert` | `icard_sign.cer` | Path to the issuer's PEM certificate |
| `--out` | `.` | Directory to save the extracted photo |

## What is verified

The RSA signature covers the SHA-256 hash of the entire signed region:

- All demographic fields: name, DOB, gender, care of, full address
- The embedded JPEG2000 face photo bytes
- Card ID last 4 digits and generation timestamp

Any modification to any of the above — including swapping the photo — will cause verification to fail. The masked email field is intentionally outside the signed region (same design as UIDAI Aadhaar QR).

## Demonstration scenarios

| Scenario | Card source | Cert source | Expected result |
|---|---|---|---|
| Genuine card | QRICard (original key) | Original cert | ✓ VALID |
| Name tampered by icardforger.py | QRICard (forged) | Original cert | ✗ INVALID |
| Card signed with a different key | QRICard (rogue key) | Original cert | ✗ INVALID |
